## 🧗 Climbing Live

Mon projet principal : une plateforme de retransmission vidéo dédiée aux compétitions d'escalade.

### Stack technique du projet

**Backend**
- Symfony
- API Platform
- Doctrine
- PostgreSQL

**Frontend**
- Next.js
- TypeScript
- TailwindCSS

**Streaming**
- MediaMTX
- FFmpeg
- WebRTC
- HLS

```text
Caméras / Smartphones
          ↓
       MediaMTX
          ↓
        FFmpeg
          ↓
     HLS / WebRTC
          ↓
       Next.js
```
